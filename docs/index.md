# Trino Provider

Terraform provider for the [Trino](https://trino.io/) control plane. It manages
catalogs, schemas, catalog roles, role grants and table privilege grants by
translating Terraform resources into Trino SQL DDL.

Every read is a SQL query and every mutation is a DDL statement. Where Trino
exposes no read path, the resource documents that its read is
state-authoritative rather than pretending to detect drift.

## Requirements

- Terraform 1.9 or later (plugin protocol 6.0).
- Trino 476 or later. The acceptance suite runs against the versions in
  [`.github/trino-versions.txt`](https://github.com/caberdo/terraform-provider-trino/blob/main/.github/trino-versions.txt).

## Quick start

```terraform
terraform {
  required_providers {
    trino = {
      source = "caberdo/trino"
    }
  }
}

provider "trino" {
  endpoint = "http://localhost:8080"
  user     = "admin"
  auth     = "none"
}
```

## Schema

### Optional

- `access_token` (String, Sensitive) Static JWT access token. Falls back to TRINO_ACCESS_TOKEN.
- `auth` (String) Authentication mode: none, basic, jwt, oauth2 or kerberos. Inferred when unset. Falls back to TRINO_AUTH.
- `ca_cert` (String) CA certificate PEM content. Conflicts with ca_cert_file. Falls back to TRINO_CA_CERT.
- `ca_cert_file` (String) Path to a CA certificate PEM file. Falls back to TRINO_CA_CERT_FILE.
- `catalog` (String) Default catalog. Falls back to TRINO_CATALOG.
- `client_cert` (String, Sensitive) Client certificate PEM content for mTLS. Conflicts with client_cert_file. Falls back to TRINO_CLIENT_CERT.
- `client_cert_file` (String) Path to a client certificate PEM file. Falls back to TRINO_CLIENT_CERT_FILE.
- `client_key` (String, Sensitive) Client private key PEM content for mTLS. Conflicts with client_key_file. Falls back to TRINO_CLIENT_KEY.
- `client_key_file` (String) Path to a client private key PEM file. Falls back to TRINO_CLIENT_KEY_FILE.
- `endpoint` (String) Trino coordinator URL, for example https://trino.example:8443. Falls back to TRINO_ENDPOINT.
- `extra_credentials` (Map of String, Sensitive) Extra credentials sent as X-Trino-Extra-Credential.
- `http_headers` (Map of String, Sensitive) Static headers added to every request, for gateway or proxy auth.
- `insecure_skip_verify` (Boolean) Skip TLS certificate verification. Use only for testing. Falls back to TRINO_INSECURE_SKIP_VERIFY.
- `kerberos_config_file` (String) Path to krb5.conf. Falls back to TRINO_KERBEROS_CONFIG_FILE.
- `kerberos_credential_cache` (String, Sensitive) Path to a FILE credential cache, for example FILE:/tmp/krb5cc_1000. Falls back to TRINO_KERBEROS_CREDENTIAL_CACHE.
- `kerberos_keytab` (String, Sensitive) Path to a Kerberos keytab. Mutually exclusive with kerberos_credential_cache. Falls back to TRINO_KERBEROS_KEYTAB.
- `kerberos_principal` (String) Kerberos principal without a realm. Falls back to TRINO_KERBEROS_PRINCIPAL.
- `kerberos_realm` (String) Kerberos realm. Required with a keytab. Falls back to TRINO_KERBEROS_REALM.
- `kerberos_service_name` (String) Kerberos service name. Defaults to HTTP. Falls back to TRINO_KERBEROS_SERVICE_NAME.
- `kerberos_service_principal_pattern` (String) Kerberos service principal pattern. Defaults to ${SERVICE}@${HOST}. Falls back to TRINO_KERBEROS_SERVICE_PRINCIPAL_PATTERN.
- `kerberos_use_canonical_hostname` (Boolean) Use the canonical hostname for the Kerberos service principal. Defaults to true. Falls back to TRINO_KERBEROS_USE_CANONICAL_HOSTNAME.
- `oauth2_client_id` (String) OAuth2 client ID for the client-credentials flow. Falls back to TRINO_OAUTH2_CLIENT_ID.
- `oauth2_client_secret` (String, Sensitive) OAuth2 client secret. Falls back to TRINO_OAUTH2_CLIENT_SECRET.
- `oauth2_scope` (String) Optional OAuth2 scope. Falls back to TRINO_OAUTH2_SCOPE.
- `oauth2_token_endpoint` (String) OAuth2 token endpoint. Required for oauth2 auth because Trino 476 has no discovery. Falls back to TRINO_OAUTH2_TOKEN_ENDPOINT.
- `password` (String, Sensitive) Password for basic auth. Requires an https endpoint. Falls back to TRINO_PASSWORD.
- `query_timeout` (String) Query timeout as a duration, default 5m. Falls back to TRINO_QUERY_TIMEOUT.
- `roles` (Map of String) Catalog to role mapping, for example { hive = "admin" }.
- `schema` (String) Default schema. Falls back to TRINO_SCHEMA.
- `session_properties` (Map of String) Session properties sent with every query.
- `source` (String) Trino source name. Defaults to terraform-provider-trino. Falls back to TRINO_SOURCE.
- `user` (String) Trino user name. Defaults to terraform. Falls back to TRINO_USER.
