# trino_catalog Resource

Manages a Trino catalog through dynamic catalog management (`catalog.management=dynamic`). Catalog properties are write-only: Trino has no read path for them, so Terraform keeps the configured values in state and cannot detect property drift. Import is not supported for the same reason.

## Example Usage

```terraform
terraform {
  required_providers {
    trino = {
      source = "caberdo/trino"
    }
  }
}

provider "trino" {
  endpoint = "http://localhost:8080"
  user     = "admin"
  auth     = "none"
}

variable "iceberg_credential" {
  type        = string
  description = "OAuth2 credential for the Iceberg REST catalog."
  sensitive   = true
}

# Catalog properties are write-only: Trino exposes no read path for them, so
# Terraform keeps the configured values in state and cannot detect property
# drift. Import is unsupported for the same reason: every attribute forces
# replacement, so importing would drop and recreate the live catalog.
resource "trino_catalog" "lakehouse" {
  name      = "lakehouse"
  connector = "iceberg"
  properties = {
    "iceberg.catalog.type" = "rest"
    "iceberg.rest.uri"     = "http://iceberg:8181"
  }
  sensitive_properties = {
    "iceberg.rest.oauth2.credential" = var.iceberg_credential
  }
}
```

## Schema

### Required

- `connector` (String) Trino connector that backs the catalog, for example `memory`, `tpch`, `hive` or `iceberg`. Must be a lowercase connector name (letters, digits and underscores, starting with a letter). Changing this forces a new catalog to be created.
- `name` (String) Name of the catalog. Trino catalog names are case-insensitive; the configured spelling is kept in state. Changing this forces a new catalog to be created.

### Optional

- `properties` (Map of String) Catalog properties passed to the connector. Every value is sent to Trino as a string literal. **Write-only:** Trino cannot read catalog properties back, so drift in this map is not detected and Terraform keeps the configured values in state. Changing this forces a new catalog to be created.
- `sensitive_properties` (Map of String, Sensitive) Catalog properties whose values are secret, merged with `properties` when the catalog is created. **Sensitive and write-only:** values are never read back from Trino and are stored in Terraform state as sensitive. Changing this forces a new catalog to be created.

### Read-Only

- `id` (String) The catalog name. This is the same value as `name`.
