# trino_grant_role Resource

Grants a catalog role to a Trino user or role. Trino cannot list another principal's role grants, so Read is state-authoritative: grants revoked outside Terraform are not detected and are not removed from state.

## Example Usage

```terraform
terraform {
  required_providers {
    trino = {
      source = "caberdo/trino"
    }
  }
}

provider "trino" {
  endpoint = "http://localhost:8080"
  user     = "admin"
  auth     = "none"
}

# Trino cannot list another principal's role grants, so Read is
# state-authoritative: a grant revoked outside Terraform is not detected and
# stays in state. Re-apply the grant (or import after removing it from state)
# if it is revoked out of band.
resource "trino_grant_role" "analyst_to_alice" {
  role         = "analyst"
  role_catalog = "hive" # required, matches trino_role.catalog
  grantee      = "alice"
  grantee_type = "USER" # USER | ROLE
  admin_option = false
}
```

## Import

Import is supported using the following syntax:

```shell
# Import ID: <role_catalog>.<role>:<grantee_type>:<grantee>
#
# Import writes state only. Trino has no general read path for another
# principal's role grants, so nothing is verified against the server and
# admin_option is imported as false. A "." in the catalog name or a ":" in any
# segment makes the ID ambiguous.
terraform import trino_grant_role.analyst_to_alice 'hive.analyst:USER:alice@example.com'
```

## Schema

### Required

- `grantee` (String) Principal receiving the role. Trino accepts arbitrary principal strings, so values such as alice@example.com and DOMAIN\alice are valid.
- `grantee_type` (String) Whether the grantee is a USER or a ROLE.
- `role` (String) Catalog role to grant.
- `role_catalog` (String) Catalog that owns the role, for example hive. Must be non-empty.

### Optional

- `admin_option` (Boolean) Whether the grantee may grant the role to other principals. Defaults to false. Changing this toggles WITH ADMIN OPTION in place. Trino cannot read this back, so changes made outside Terraform are not detected.

### Read-Only

- `id` (String) Stable identifier in the form role_catalog.role:grantee_type:grantee.
