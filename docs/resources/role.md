# trino_role Resource

Manages a catalog role in Trino. System roles are a documented non-goal: Stock Trino disables system roles (N1b), so trino_role only manages catalog roles.

## Example Usage

```terraform
resource "trino_role" "analyst" {
  name    = "analyst"
  catalog = "hive" # required: system roles are disabled on stock Trino
}
```

## Import

Import is supported using the following syntax:

```shell
terraform import trino_role.analyst hive.analyst
```
