# trino_schema Resource

Manages a schema in a Trino catalog. The owner can be changed in place; properties and the catalog or schema name force replacement.

## Example Usage

```terraform
terraform {
  required_providers {
    trino = {
      source = "caberdo/trino"
    }
  }
}

resource "trino_schema" "sales" {
  catalog       = "lakehouse"
  name          = "sales"
  owner         = "alice"
  owner_type    = "USER"
  properties    = { location = "s3://bucket/sales" }
  force_destroy = false
}
```

## Import

Import is supported using the following syntax:

```shell
terraform import trino_schema.example catalog.schema
```

## Schema

### Required

- `catalog` (String) Catalog that contains the schema.
- `name` (String) Schema name. Hive lowercases it; the configured spelling is kept in state.

### Optional

- `force_destroy` (Boolean) Drop the schema with CASCADE, including its contents. Defaults to false.
- `owner` (String) Schema owner. Defaults to the creating user when unset.
- `owner_type` (String) Owner principal type, USER or ROLE. Defaults to USER when owner is set.
- `properties` (Map of String) Schema properties passed as WITH (key = 'value'). Changing them forces replacement.

### Read-Only

- `id` (String) Identifier in the form catalog.name.
